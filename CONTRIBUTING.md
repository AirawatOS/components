# Contributing

This repository is one of the five AirawatOS repositories. How a change reaches `main` — branches, **signed commits**,
`make verify` on a proven-empty slate, pull requests with one review (a **second reviewer** for core paths via CODEOWNERS),
merge commits only, and the image policy — is defined once for all of them in the root repository:
[`CONTRIBUTING.md`](https://github.com/AirawatOS/airawatos/blob/main/CONTRIBUTING.md).

Local install for developers: [`docs/operator/INSTALL-LOCAL.md`](https://github.com/AirawatOS/airawatos/blob/main/docs/operator/INSTALL-LOCAL.md).
